Proyecto: Sistema de Farmacia e Inventario (BD + Backend + Frontend + n8n)

Al separar la arquitectura en 4 instancias independientes, cada servicio
cuenta con sus propios recursos de RAM y disco duro (evitando que n8n
sature la memoria o el almacenamiento del Backend).

----------------------------------------------------------------------
PASO 1: INSTANCIA 1 (Base de Datos PostgreSQL)
----------------------------------------------------------------------
Conéctate por SSH o consola a la Instancia 1 y ejecuta:

1- git clone https://github.com/mildred93-code/ProyectoTaller.git
2- cd ProyectoTaller/scripts
3- bash setup-db.sh

¿Qué hace este script?
- Instala PostgreSQL.
- Crea la base de datos 'farmacia_inventario' y el usuario 'farmacia_user'.
- Ejecuta automáticamente 'tablas_farmacia.sql' y las migraciones de lotes y código de barras.
- Configura PostgreSQL para permitir conexiones remotas (puerto 5432).
- Al finalizar, te mostrará la IP en pantalla.
👉 COPIA ESA IP (la necesitarás para la Instancia 2 de Backend y la Instancia 4 de n8n).

----------------------------------------------------------------------
PASO 2: INSTANCIA 2 (Backend Express)
----------------------------------------------------------------------
Conéctate por SSH o consola a la Instancia 2 y ejecuta:

1- git clone https://github.com/mildred93-code/ProyectoTaller.git
2- cd ProyectoTaller/scripts
3- bash setup-backend.sh

¿Qué hace este script?
- Te pedirá la IP de la Instancia 1 (Base de Datos).
- Instala Node.js 22 LTS y las dependencias del backend.
- Genera el archivo '.env' conectado a 'farmacia_inventario'.
- Abre el puerto 4000 e inicia el servidor Express.
- Al finalizar, te mostrará la IP Pública de la Instancia 2.
👉 COPIA ESA IP (la necesitarás para el Frontend).

----------------------------------------------------------------------
PASO 3: INSTANCIA 3 (Frontend React / Vite)
----------------------------------------------------------------------
Conéctate por SSH o consola a la Instancia 3 y ejecuta:

1- git clone https://github.com/mildred93-code/ProyectoTaller.git
2- cd ProyectoTaller/scripts
3- bash setup-frontend.sh

¿Qué hace este script?
- Te pedirá la IP Pública de la Instancia 2 (Backend).
- Instala Node.js 22, las dependencias de React y el lector de código de barras (html5-qrcode).
- Configura la conexión dinámica hacia http://<IP_BACKEND>:4000/api.
- Inicia Vite en el puerto 5173 accesible públicamente.
👉 Abre en tu navegador: http://<IP_INSTANCIA_3>:5173

----------------------------------------------------------------------
PASO 4: INSTANCIA 4 (n8n + ngrok)
----------------------------------------------------------------------
Conéctate por SSH o consola a la Instancia 4 y ejecuta:

1- git clone https://github.com/mildred93-code/ProyectoTaller.git
2- cd ProyectoTaller/scripts
3- bash setup-n8n.sh

¿Qué hace este script?
- Te pedirá la IP de la Instancia 1 (Base de Datos) para tenerla a la mano en n8n.
- Te pedirá tu Authtoken y dominio de ngrok (o Enter para usar el predeterminado).
- Configura 1 GB de Swap y limpia temporales para que n8n se instale sin agotar la RAM ni el disco.
- Instala Node.js 22, n8n y ngrok.
- Importa automáticamente el flujo 'My workflow Farmacia.json'.
- Inicia n8n en el puerto 5678 y ngrok apuntando al túnel seguro HTTPS para Telegram.
👉 Abre en tu navegador: http://<IP_INSTANCIA_4>:5678
