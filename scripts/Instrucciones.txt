======================================================================
GUÍA DE INSTALACIÓN Y DESPLIEGUE EN AWS (3 INSTANCIAS EC2 UBUNTU)
Proyecto: Sistema de Inventario de Farmacia (Backend + Frontend + n8n + ngrok)
======================================================================

Debes realizar la configuración de tus 3 instancias en el siguiente orden
para que se enlacen correctamente entre sí.

----------------------------------------------------------------------
PASO 0: CONFIGURACIÓN DE GRUPOS DE SEGURIDAD (REGLAS DE ENTRADA EN AWS)
----------------------------------------------------------------------

1. Instancia 1 (Base de Datos PostgreSQL):
   - Tipo: PostgreSQL
   - Puerto: 5432
   - Origen: Anywhere-IPv4 (0.0.0.0/0)

2. Instancia 2 (Backend + n8n + ngrok):
   - Regla 1:
     * Tipo: TCP Personalizado
     * Puerto: 4000 (API Backend Express)
     * Origen: Anywhere-IPv4 (0.0.0.0/0)
   - Regla 2:
     * Tipo: TCP Personalizado
     * Puerto: 5678 (Interfaz Web de n8n)
     * Origen: Anywhere-IPv4 (0.0.0.0/0)

3. Instancia 3 (Frontend Vite/React):
   - Tipo: TCP Personalizado
   - Puerto: 5173 (Frontend Web)
   - Origen: Anywhere-IPv4 (0.0.0.0/0)

----------------------------------------------------------------------
PASO 1: INSTANCIA 1 (Base de Datos PostgreSQL)
----------------------------------------------------------------------
Conéctate por SSH o consola a la Instancia 1 y ejecuta:

1- git clone https://github.com/mildred93-code/ProyectoTaller.git
2- cd ProyectoTaller/scripts
3- bash setup-db.sh

¿Qué hace este script?
- Instala PostgreSQL.
- Crea la base de datos 'farmacia_inventario' y el usuario 'farmacia_user'.
- Ejecuta automáticamente 'tablas_farmacia.sql' y las migraciones de lotes y código de barras.
- Configura PostgreSQL para aceptar conexiones remotas.
- Al terminar, te imprimirá en pantalla la IP de esta máquina.
👉 COPIA ESA IP para usarla en el siguiente paso.

----------------------------------------------------------------------
PASO 2: INSTANCIA 2 (Backend + n8n + ngrok)
----------------------------------------------------------------------
Conéctate por SSH o consola a la Instancia 2 y ejecuta:

1- git clone https://github.com/mildred93-code/ProyectoTaller.git
2- cd ProyectoTaller/scripts
3- bash setup-backend.sh

¿Qué hace este script?
- Te pedirá la IP de la Instancia 1 (Base de Datos) que copiaste en el paso anterior.
- Te pedirá tu Authtoken y dominio de ngrok (o puedes presionar Enter para usar el dominio predeterminado).
- Instala Node.js 20, n8n y ngrok automáticamente.
- Instala dependencias y genera el archivo '.env' con la base 'farmacia_inventario'.
- Levanta al mismo tiempo:
    * Backend en el puerto 4000
    * n8n en el puerto 5678
    * ngrok apuntando al puerto 5678 (para los webhooks seguros HTTPS de Telegram)
- Al terminar, te mostrará la IP Pública de la Instancia 2.
👉 COPIA ESA IP para el Frontend.

----------------------------------------------------------------------
PASO 3: INSTANCIA 3 (Frontend React / Vite)
----------------------------------------------------------------------
Conéctate por SSH o consola a la Instancia 3 y ejecuta:

1- git clone https://github.com/mildred93-code/ProyectoTaller.git
2- cd ProyectoTaller/scripts
3- bash setup-frontend.sh

¿Qué hace este script?
- Te pedirá la IP Pública de la Instancia 2 (Backend).
- Instala Node.js 20 y las dependencias del frontend.
- Configura la conexión de la API hacia http://<IP_BACKEND>:4000/api.
- Inicia el servidor de desarrollo de Vite en el puerto 5173 accesible públicamente.
